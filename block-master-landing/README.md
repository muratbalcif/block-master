# Block Master — Tanıtım Sayfası

Instagram biyografisi için hazırlanmış, mobil uyumlu statik GitHub Pages sayfası.

## Yayınlama

1. GitHub'da `block-master` adlı **public** depo oluşturun.
2. `index.html` dosyasını deponun köküne yükleyin.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Yayın adresi: `https://muratbalcif.github.io/block-master/` (depo adı aynıysa).
5. Instagram biyografisine bu adresi ekleyin.

Not: Instagram uygulama içi tarayıcısı Google Play'e geçişi her zaman garanti etmez; sayfa alternatif mağaza bağlantısı da içerir.
